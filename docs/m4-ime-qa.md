# M4 IME 专项 QA

手工矩阵，覆盖 macOS WKWebView 与 Windows WebView2。使用系统拼音（macOS 简体拼音 / Windows 微软拼音）。语法讲解内容始终为中文，不随界面语言变化。

## 环境

- macOS：把 App 放到 `/Applications` 后再测开机自启；开发目录启动时设置页应提示无法注册。
- Windows：确认自启写入后重启仍生效。
- 主题：浅 / 深 / 跟随系统；切换后两个窗口同步且无白闪。
- 语言：中文 / English / 跟随系统。

## 用例

| # | 步骤 | 期望 |
|---|---|---|
| 1 | 面板搜索框输入拼音，候选框出现 | 候选框贴着插入符，不跑到窗口外或错位 |
| 2 | 连续输入多个音节再选词 | 输入框不被重建；已上屏文字不被清空 |
| 3 | 回车选词 | 只确认候选，不提交翻译/语法 |
| 4 | Esc 关闭候选 | 只关候选框，面板保持打开 |
| 5 | 候选未上屏时按 Tab | 不切换模式 |
| 6 | 上屏后按 Tab | 切换模式，焦点仍在搜索框 |
| 7 | 点结果区文字并拖选 | 不把焦点抢回搜索框 |
| 8 | 组合输入中途切主题/语言 | 正在输入的拼音不被打断或清空 |
| 9 | 热键唤起后面板搜索框拼音输入 | 可直接打字；候选跟随光标 |
| 10 | 打开独立设置窗口，在 Key / URL 输入框用拼音 | 候选跟随；Tab 在表单控件间移动，不切面板模式 |
| 11 | `⌘,` / `Ctrl-,` 打开设置；关闭设置后再打开 | 关闭即销毁；再次打开是新窗口 |
| 12 | 设置里开关开机自启 | 状态来自系统；失败时开关回滚并给出提示 |

发现平台 glue 问题（标题栏抢焦点、GotFocus 未送达）时，分别修 AppKit / WebView2 路径，不要在 Web 层用 hack 假装过关。
